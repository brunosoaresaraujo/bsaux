# BSAUX - Premium Landing Page

Este é o repositório da landing page oficial da **BSAUX**, focada em design de experiência, interfaces de alta performance e estratégia com IA.

## 🚀 Tecnologias Utilizadas

- **HTML5** & **Semantic Tags**
- **Tailwind CSS** (via CDN para prototipagem rápida e estilização utilitária)
- **Vanilla JavaScript** (Lógica de interatividade, animações de scroll e efeitos parallax)
- **Lucide Icons** (Sistema de ícones vetoriais)
- **Custom CSS Animations** (Keyframes cinematográficos e efeitos de vidro)

## 📁 Estrutura do Projeto

```text
bsaux/
├── assets/
│   ├── css/          # Estilização externa (main.css)
│   ├── js/           # Lógica de interatividade (main.js)
│   ├── img/          # Imagens, logotipos e fotos de perfil
│   └── video/         # Vídeos de demonstração do portfólio
├── index.html        # Estrutura principal da página
├── styleguide.html   # Guia de estilos e componentes
└── README.md         # Documentação do projeto
```

## ✨ Funcionalidades

- **Signature Hero**: Efeito parallax 3D no mouse e iluminação dinâmica.
- **Processo Estratégico**: Linha do tempo interativa que cresce com o scroll.
- **Stack de Projetos**: Cards de vídeo que se empilham com scroll e tocam ao passar o mouse.
- **Design Responsivo**: Adaptado para todos os dispositivos.
- **Estética Dark-Mode**: Interface premium com técnicas de Glassmorphism e gradientes suaves.

## 🛠️ Como Executar

1. Clone o repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Para uma experiência completa, utilize uma extensão de Live Server.
